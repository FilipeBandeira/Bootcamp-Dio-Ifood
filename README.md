# Potência Tech Angular Developer — DIO e iFood

Repositório de exercícios do bootcamp Potência Tech Angular Developer, com fundamentos de JavaScript, TypeScript e aplicações de estudo em Angular.

## Organização

| Pastas | Conteúdo |
| --- | --- |
| `1.Condicionais/` a `5.Importação/` | Fundamentos de programação e organização de código |
| `6.Components/`, `7.Typescript/` | Exercícios de componentes e TypeScript |
| `diretivas-proj/` | Aplicação Angular de estudo de diretivas |
| `life-cycle/` | Aplicação Angular de estudo de ciclo de vida |

## Como executar

Cada aplicação Angular possui seu próprio `package.json`. No ambiente histórico compatível:

```sh
git clone https://github.com/FilipeBandeira/Bootcamp-Dio-Ifood.git
cd Bootcamp-Dio-Ifood/diretivas-proj
npm ci
npm start
```

Para o outro exemplo, repita em `life-cycle/`. Abra `http://localhost:4200`. Os arquivos de exercícios são independentes; leia o código antes de escolher execução no navegador ou no Node.js.

`node_modules` é gerado na instalação e fica fora do controle de versão. Os manifests e lockfiles permanecem como referência para restaurar as dependências.

## Escopo

Exemplos educacionais do bootcamp, sem backend compartilhado ou aplicação única integrada. Os créditos do curso e dos materiais originais são preservados.

## Compatibilidade e evolução

O projeto utiliza **Angular 14**, uma versão sem suporte atual. O ambiente histórico compatível usa Node.js 16.20.x, também fora de suporte, e TypeScript 4.7. Use esse ambiente apenas para reproduzir o projeto de estudo. A prioridade para uma evolução destinada a publicação é migrar Angular e Node para versões mantidas, revisar dependências e validar a aplicação. Consulte a [matriz oficial de compatibilidade](https://angular.dev/reference/versions).
